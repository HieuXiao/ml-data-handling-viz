# Machine Learning Data Handling & Visualization

Dự án này được xây dựng để giải quyết các bài tập về xử lý và trực quan hóa dữ liệu máy học.

## Cấu trúc dự án
- **Code/**: Chứa mã nguồn giải quyết các bài toán.
- **Data/**: Thư mục chứa các tệp dữ liệu thô phục vụ cho quá trình phân tích.
- **Document/**: Nơi lưu trữ đề cương và các tài liệu tham khảo.
- **requirements.txt**: Chứa danh sách các thư viện Python cần thiết cho dự án.

## Hướng dẫn chạy dự án

Yêu cầu sử dụng phiên bản **Python 3.11** để đảm bảo tương thích tốt nhất.

1. Tạo và kích hoạt môi trường ảo (nếu cần):
   ```bash
   python -m venv venv
   venv\Scripts\activate  # Đối với Windows
   # source venv/bin/activate  # Đối với macOS/Linux
   ```
2. Cài đặt các thư viện bắt buộc:
   ```bash
   pip install -r requirements.txt
   ```
3. Mở file Notebook (`.ipynb`) nằm trong thư mục **Code/** bằng các trình biên tập hỗ trợ Jupyter (như Visual Studio Code hoặc Jupyter Lab).
4. Chọn Kernel Python 3.11 (hoặc môi trường `venv` vừa tạo) và bấm **Run All** (hoặc chạy từng cell) để xem kết quả.
